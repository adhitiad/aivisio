# Engineering Tasks

Setiap task harus menyatakan:
- status: proposed / ready / in_progress / blocked / done;
- tujuan dan non-goals;
- dependency;
- file/komponen yang perlu dianalisis;
- acceptance criteria yang dapat diuji;
- security, data, dan operational risks;
- test plan dan rollout/rollback plan.

Task berikutnya yang diusulkan tercatat pada `P3.9-NEXT.md`. Task tersebut belum merupakan izin untuk mulai coding.
