# Engineering Tasks

Folder ini berisi task implementasi yang ditugaskan, diusulkan, atau sedang berjalan. Task harus terhubung ke [AIVISO Master Roadmap](../workflows/AIVISO-MASTER-ROADMAP.md) dan menyebutkan master phase serta workstream terkait.

## Identitas dan status task

Setiap task harus menyatakan:
- status: proposed / ready / in_progress / blocked / done;
- master phase (PHASE 0–PHASE 8);
- workstream/namespace bila task lintas fase;
- tujuan dan non-goals;
- dependency;
- file/komponen yang perlu dianalisis;
- acceptance criteria yang dapat diuji;
- security, data, dan operational risks;
- test plan dan rollout/rollback plan.

## Penomoran

- Master PHASE 0–PHASE 8 adalah fase tingkat produk.
- Priority P0/P1/P2 adalah kelas prioritas fitur.
- Task YouTube Publishing lama dengan ID P3.1–P3.9 wajib disebut **YouTube Publishing P3.x**, bukan Master PHASE 3.
- Task baru harus memakai nama/ID yang menyebutkan workstream agar tidak ambigu.
