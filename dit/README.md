# DIT — Development, Implementation & Task Handoff

Folder `dit/` adalah pusat workflow engineering dan handoff agent AIVISO.

- `workflows/`: urutan milestone, dependency, dan definisi alur kerja.
- `tasks/`: task aktif/berikutnya dengan scope dan acceptance criteria.
- `context/`: kondisi repository, keputusan, batasan, dan handoff agent.

## Cara agent memulai

1. Baca `../docs/RULES.md` dan `../.agents/README.md`.
2. Baca `context/PROJECT-STATE.md` dan `context/AGENT-HANDOFF.md`.
3. Baca roadmap dan task yang ditugaskan.
4. Verifikasi semua status terhadap branch dan CI terbaru sebelum bertindak.

Dokumen ini tidak menggantikan kode, tests, Git history, atau hasil CI sebagai bukti.
